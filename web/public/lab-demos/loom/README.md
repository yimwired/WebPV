# Loom demo photography

Stock photographs standing in for a guesthouse's own, used by `/labs/loom`.

Source: Unsplash, fetched 2026-09-17. The Unsplash License allows commercial and
non-commercial use with no permission and no attribution required, so these are
safe on a portfolio. They are still stand-ins: a real client's site ships with
the client's own photographs, and these get deleted the moment that happens.

Picked for one thing above subject matter, which is warm daylight on wood. Four
rooms of a guesthouse have to read as four rooms of the same building, and stock
cannot promise that, so the only lever is tone. Anything cool, grey or evening
lit was rejected however good it was on its own.
